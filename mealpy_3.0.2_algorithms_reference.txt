MEALPY 3.0.2 - ALGORITHMS AND VARIANTS REFERENCE
=====================================================

PURPOSE
This file is ONLY a visual reference for choosing names in DEFAULT_OPTIMIZERS.
It does not contain algorithm implementations.

FORMAT
  [YEAR]  NAME_TO_USE  --->  ACTUAL_MEALPY_CLASS  |  Name / family

EXAMPLES
  [1995] PSO        ---> OriginalPSO
  [2019] PPSO       ---> PPSO
  [2014] GWO        ---> OriginalGWO
  [2019] RW_GWO     ---> RW_GWO
  [1997] DE         ---> OriginalDE
  [2009] JADE       ---> JADE
  [2013] SHADE      ---> OriginalSHADE
  [2014] L_SHADE    ---> L_SHADE

RULE FOR main_best.py
- For the original algorithm, use the acronym/family name: PSO, GWO, WOA, DE, HHO, etc.
- For a variant, use the exact variant name: PPSO, RW_GWO, JADE, L_SHADE, etc.
- The resolver should first try the name exactly as written; if it does not exist, try Original+name, Base+name, and Dev+name.
- Project-specific optimizers (MaCRO-DE, DSADE, DSADE_AWAD, DBO) are handled separately.

SOURCE NOTE
- List based on the official MEALPY v3.0.2 README/source code.
- The official PyPI 3.0.2 page reports 215 total algorithms; the v3.0.2 README contains 211 unique constructors explicitly shown in its examples.
- When the historical table and examples differ, this reference prioritizes the class name used by the v3.0.2 examples/source code.
